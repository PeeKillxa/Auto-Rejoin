# Auto-Rejoin

- [Auto-Rejoin-PC](Auto-Rejoin-PC): Nexus สำหรับ Roblox บน Windows พร้อมอัปเดตในโปรแกรม และเปิด/ปิด rejoin รายบัญชี
- [Auto-Rejoin-Emu](Auto-Rejoin-Emu): ชุด Emulator เดิม (MuMu / LDPlayer / BlueStacks)

ไฟล์ Emulator ที่ root คงไว้เป็นช่องทางเปลี่ยนผ่านสำหรับเครื่องที่ใช้ updater รุ่นเก่า ตัว updater ที่ root จะเปลี่ยนไปอ่านช่องทาง Auto-Rejoin-Emu อัตโนมัติ ส่วน PC ใช้ช่องทางแยกและไม่แตะ config ของ Emulator
