NEXUS ROBLOX MANAGER — เริ่มต้นใช้งาน
รุ่นสำหรับ Roblox PC บน Windows 10/11

ใน ZIP มีโปรแกรมและคู่มือ ใช้บัญชีและการตั้งค่า Real ของเครื่องผู้ใช้เอง

เริ่มใช้งาน
1. ติดตั้ง Real และ Roblox ใช้ Windows user เดียวกับที่จะเปิด Nexus
2. ตั้งค่า Real และคลังบัญชีให้พร้อม กำหนดเกมใน Saved launch targets รายการแรก
3. เปิด Auto Inject / Auto Attach, All Instances และ Auto Execute ใน Real
   ปิด Auto Rejoin / Auto Relaunch ของ Real เพื่อให้ Nexus จัดการ rejoin
4. เปิดบัญชีเข้าเกมผ่าน Real ก่อนหนึ่งครั้ง แล้วเปิด Nexus Auto-Rejoin

ล็อกอิน Roblox ผ่าน Nexus · รอ 15 นาที
กด บัญชี Roblox → เพิ่มบัญชี Roblox · รอ 15 นาที
กรอกชื่อผู้ใช้ รหัสผ่าน CAPTCHA และรหัส 2 ชั้นบนหน้าเว็บไซต์ Roblox ตามปกติ
เมื่อยืนยันสำเร็จ ตรวจชื่อบัญชีและ User ID แล้วกด เพิ่มบัญชีนี้เข้า Real
Nexus จะตรวจบัญชีอีกครั้ง ปิด Real ชั่วคราว และนำเข้าบัญชีที่เลือก
จากนั้นเปิด Real เพื่อดูบัญชีและเปิดเกมตามเดิม
รองรับ Real 3.1.1 และ 3.2.1 แบบ device vault ของ Windows user เดียวกัน
Nexus ตรวจรุ่นและคลังบัญชีก่อนเปิดหน้าล็อกอิน
คลังแบบใส่รหัสผ่านหรือ Real รุ่นอื่นยังไม่รองรับ มีสำรองข้อมูลเดิมแบบเข้ารหัสก่อนนำเข้า
เป็นส่วนเชื่อมต่อข้อมูลในเครื่องของ Nexus ต้องตรวจบัญชีจริงใน Real หลังนำเข้าครั้งแรก

ปิด Real ให้หมด
ในหน้าบัญชี Roblox มีปุ่มปิด Real ให้หมด รวมโปรเซสค้างใน Task Manager
หาก Real ใช้สิทธิ์แอดมิน Windows จะขออนุญาต ต้องใช้ Windows user เดียวกับ Nexus
การนำเข้าจะตรวจว่าปิดครบก่อนเขียนข้อมูล

ปุ่มหลัก
F9 = จัดเรียงหน้าต่าง Roblox
F10 = ซ่อน / แสดงหน้าต่าง
Rejoin จอที่เลือก = ปิดโปรเซสเก่า รอยืนยันว่าปิดแล้ว แล้วจึงเปิดใหม่
Rejoin ทุกจอ = เข้าคิวเปิดใหม่ตามบัญชีที่เปิด Auto Rejoin

ซ่อนจอหลัง Rejoin
กดซ่อนทุกจอเพื่อซ่อนจากหน้าจอ Taskbar และ Alt+Tab พร้อมจำค่าไปยังจอที่เปิดใหม่
กดแสดงทุกจอหรือ F10 เพื่อแสดงกลับ เลือกแสดงเฉพาะบัญชีได้

เปิด-ปิด Auto Rejoin รายบัญชี
คลิกคอลัมน์ Auto Rejoin หรือเลือกหลายแถวแล้วคลิกขวาเปิด/ปิด
การปิดจะยกเลิกคิวของบัญชีนั้น ค่าจะจำไว้หลังเปิดโปรแกรมใหม่
บัญชีที่ลบจาก Real จะถูกยกเลิกคิวและลืมข้อมูลใน Nexus

อัปเดตจาก GitHub
โปรแกรมตรวจอัปเดตตอนเปิดและทุก 30 นาที หรือกดตรวจอัปเดตด้านบน
การติดตั้งรอ Nexus เดิมปิด เก็บไฟล์เก่าและคงการตั้งค่าเดิม
เพื่อนที่ใช้รุ่นไม่มี updater ต้องลงแพ็กเกจนี้ครั้งเดียว

ข้อมูลและข้อจำกัด
การตั้งค่าและ log อยู่ใน AppData ของ Windows user แต่ละเครื่อง
ใช้ Saved launch targets รายการแรก server ว่างหรือเป็น Job ID ได้
ลิงก์เชิญ private server / share link ยังไม่รองรับ
การอ่านบัญชีรองรับ dev:v1 และ plaintext ของรุ่นที่ตรวจสอบแล้ว
ตัวเบราว์เซอร์ใช้ Microsoft Edge WebView2 Runtime ที่ติดตั้งใน Windows
หากเครื่องไม่มี Runtime หน้าล็อกอินจะแสดงลิงก์ดาวน์โหลดของ Microsoft

ตัวปรับเวลาเดิมของ Real (ทดลอง)
เข้าทาง บัญชี Roblox → ตัวปรับเวลาเดิมของ Real
Windows Security บล็อกไฟล์ขณะปรับเวลา: Nexus จะพักวิธีนี้ใน Real รุ่นที่ถูกบล็อก
ตรวจรายละเอียดได้ที่ Windows Security → Protection history
ฟีเจอร์เวลาล็อกอินยังเป็นรุ่นทดลองสำหรับวิธีแก้ไฟล์เดิม หน้าล็อกอิน Nexus ใช้เบราว์เซอร์แยก
